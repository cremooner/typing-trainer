# 盲打训练器

单文件网页版英文盲打训练器。双击 `index.html` 即用，无框架、无构建、无网络依赖，离线可跑。

## 用法

直接打开 `index.html`。成绩、逐键统计和设置存在浏览器 `localStorage`，可导出 / 导入 JSON 备份。

六种模式：键位（17 级递进课程）、单词（词典词卡）、句段（词组搭配）、文章、冲刺（限时）、弱键。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 全部成品，HTML + CSS + 原生 JS，词库与句段语料已内联 |
| `CET6_2.json` | 原始词库（JSONL，每行一条），仅作数据源，页面运行不依赖它 |
| `test/e2e.js` | 端到端测试，用 playwright-core 驱动本机 Chrome 真敲键盘跑完整流程 |
| `打字训练器-设计方案.md` | 设计文档：模式、判定口径、指标定义、修订记录 |
| `打字训练器-评审与优化建议.md` | 外部评审记录（修订前的原始意见） |
| `短语搭配-对照表.md` / `.txt` | 句段语料的整理稿与纯文本练习版 |

## 测试

```bash
npm i playwright-core
node test/e2e.js
```

需要本机装 Chrome 或 Edge（可用 `CHROME_CHANNEL` 环境变量指定），截图输出到系统临时目录。

## 数据来源

- 单词与例句取自 [kajweb/dict](https://github.com/kajweb/dict) 的 `CET6_2.json`（原始来源为某背单词 App 的抓取数据），
  本项目仅摘取词形、音标、中文释义与首条例句内联展示。
- 句段语料（100 条）为本项目手写。
- 以上语料仅供个人学习使用，不作商业用途。如有侵权请联系删除。
